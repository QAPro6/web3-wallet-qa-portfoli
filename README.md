# Web3 Wallet QA Portfolio

## Purpose
This repository documents my learning journey and QA portfolio for Web3 wallet testing.

## Repository Structure
- `docs/test-cases/` - Manual test cases for wallet functionalities
- `docs/bug-reports/` - Bug reports with reproduction steps
- `scripts/` - Automation scripts for wallet testing
- `learning-notes/` - Daily learning notes and concepts

## Testing Focus Areas
- Wallet installation & initialization
- Token transfer & transaction signing
- dApp connection & permissions
- Security: private key & seed phrase management
- Multi-chain wallet behavior

## Tools
- MetaMask
- OKX Wallet
- Rabby Wallet
- Playwright / Selenium for automation
- Hardhat for local blockchain testing (planned)
